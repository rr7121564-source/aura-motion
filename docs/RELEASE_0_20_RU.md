# True Motion 0.20.0

Восемь пунктов плана 0.20.0 реализованы в Android на основе AbsentMotion 5.0.3. Локальная тестовая сборка проверена через ADB в MuMu. [Подробные результаты](TRUE_MOTION_020_VALIDATION.md).

## Импорт проекта по ссылке

На вкладке «Проекты» рядом с импортом `.alight / XML` появилась кнопка «По ссылке». Вставь ссылку Alight Motion и нажми «Импорт». Проект с включёнными в пакет медиа появится в списке проектов. Загрузку можно отменить; недоступные ссылки и неполные пакеты показывают ошибку.

## Работа с текстом

В категории текстовых эффектов появились **Аниматор символов** и **Интервалы текста+**. Аниматор работает с символами, словами или строками. Для одной буквы выбери диапазон и укажи одинаковые номера первого и последнего символов, начиная с 1. Можно менять положение, поворот, независимый XY-масштаб, якорь, цвет и прозрачность, добавлять обычные ключи. Для нескольких независимых букв добавь несколько экземпляров эффекта.

Интервалы текста+ отдельно меняют расстояние между символами, словами и строками с выбором фиксированного края. Текст сохраняет векторные контуры. Исправлены согласованность размеров очень крупного шрифта и границы эффектов после трансформации символов.

## GLB и кости

Импортируй GLB обычным способом добавления 3D-модели. У модели со скелетом кнопка «Риггинг» открывает вкладку костей. Выбери кость по имени или через поиск, настрой XYZ-положение, поворот и масштаб. Ромб добавляет ключ к выбранному параметру; числовые поля, таймлайн и графики работают как у других свойств. Правки сохраняются в проекте.

В «Параметры модели → Анимация» можно выбрать исходную позу или готовый клип из GLB, изменить скорость, начальное смещение и зацикливание. Собственные ключи костей добавляются к выбранному клипу. Переключатель «Показать все узлы» находится в выборе кости и открывает также вспомогательных родителей скелета.

## Остальные изменения

- Выбор родителя показывает превью, полное имя и номер слоя; поддерживает поиск и прокрутку.
- Графики получили циклический отскок, Snap и Back In/Out. При 100% упругости высота повторов сохраняется.
- Продление рисунка продлевает весь связанный риг, включая IK-концы; ключи сохраняют абсолютное время.
- Сохранено исправление Motion Blur из базовой версии 5.0.3.

APK в workspace — локальная тестовая сборка с debug-подписью. Она отличается от подписи GitHub release и не устанавливается поверх приложения с другим сертификатом. Физические телефоны и новый desktop-бинарник в этой работе не проверялись.
