# True Motion 0.20.0 — рабочее состояние

Цель: закончить весь список 0.20.0 из ROADMAP_RU.md. Промежуточный APK не означает завершение выпуска. Основа — AbsentMotion v5.0.3, b9e07a5a17d3f4d6f176dbd05e0e1a7a80abd6df.

## Реализовано и проверено

- Продление связанного рисунка расширяет диапазон всего скелета, включая непривязанные к рисунку конечные кости с IK-целями. Ключи сохраняют абсолютное время. Нормализация применяется при загрузке, редактировании и перед передачей сцены рендереру, включая вложенные группы. Неиспользуемые риги не изменяются.
- Запросы матрицы, локальных границ и якоря устанавливают контекст сцены. Матрица больше не использует решение IK от предыдущей версии сцены при том же времени. Аналогичная поправка запроса матрицы внесена в desktop bridge; desktop-бинарник ещё не проверен.
- Отскок допускает 100% упругости, последний повторяющийся участок больше не исчезает. Добавлены цикличный отскок, резкий переход и два пресета с выходом за диапазон. Список графиков прокручивается. Формат кривых остаётся совместимым с существующими проектами.
- Новый выбор родителя: превью с существующим ограниченным кэшем, полные переносимые имена, поиск, номер слоя в таймлайне, отметка текущего родителя, исключение связей с потомками. Отдельно поддерживается выбор для нескольких слоёв.
- Исправление Motion Blur из v5.0.3 сохранено: четыре режима Motion/Shutter Blur дают 256–1984 видимых пикселей за пределами исходного медиаквадрата на каждом GPU backend.

## Свидетельства

- JVM: 2033 теста / 299 классов, 0 ошибок, 50 предположений среды. После окончательной поправки подписи графика повторно прошли все 16 затронутых тестов.
- MuMu, OpenGL и Graphite/Vulkan: расширенный риг сохраняет идентичный кадр после исходного конца и после открытия проекта. Ошибка IK-цели уменьшена с 31.200377 до 0.047755 пикселя.
- Оба backend: периодический отскок имеет одинаковую высоту и обратную кривую; максимальная ошибка контрольных точек 1.8e-7.
- Исходный проект пользователя с привязкой: 52 случая поворота/растяжения на backend, ни одного отличающегося канала выше допуска 2/255. Стресс: 160 костей, 80 перепривязок и 240 показанных кадров на backend.
- ADB: меню с 63 слоями открывается, листается, ищет, различает одинаковые имена, переносит длинные названия и сохраняет положение после привязки. Проверены альбомная и портретная ориентации, а также цикличный график в редакторе. Временные настройки поворота MuMu восстановлены.
- Native/source hashes и source audit прошли. Сжатый и подписанный APK содержит те же файлы приложения, что Gradle APK, и установленный APK совпадает по SHA-256. Сертификат — локальный debug, отличается от сертификата GitHub release.

Отчёты и скриншоты: workspace `work/analysis/020-validation`.

## Продолжается

- Импорт проекта по реальной ссылке Alight Motion, включая пакет и медиа.
- Новые посимвольные инструменты текста.
- Риги GLB: импорт скелета/весов, готовые анимации, редактирование костей и собственные ключи.
- Оставшийся случай обрезания эффектов крупного текста. Проверка Drop Shadow на тексте в 1–1000 раз крупнее не обнаружила потерянных пикселей относительно рендера с большим полем, но это не доказывает исправление всех эффектов и всех исходных проектов.

На физическом телефоне пользователя эти изменения не проверены. GitHub release не опубликован.
