# True Motion 0.20.0 — рабочее состояние

Все восемь пунктов плана 0.20.0 реализованы в Android и проверены в MuMu. Основа — AbsentMotion v5.0.3, b9e07a5a17d3f4d6f176dbd05e0e1a7a80abd6df.

Подробная матрица реализации, проверок и ограничений: [TRUE_MOTION_020_VALIDATION.md](TRUE_MOTION_020_VALIDATION.md). План: [ROADMAP_RU.md](ROADMAP_RU.md).

Проверки: 2044 JVM-теста / 301 класс, 0 ошибок, 50 предположений среды. Нативные проверки GLB, текста, графиков и продления рига проходят на OpenGL и Graphite/Vulkan. В интерфейсе проверены импорт настоящей ссылки с медиа, поиск/прокрутка родителей, графики, выбор клипов и костей GLB, собственные ключи головы модели и сохранение проекта. Для управления использовался ADB.

Локальный APK использует debug-подпись. Desktop bridge обновлён в исходниках; новый desktop-бинарник и физические телефоны в этой работе не проверялись. GitHub release не опубликован. Источники и авторы оригинальной базы сохранены.
