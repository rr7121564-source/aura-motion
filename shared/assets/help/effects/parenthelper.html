Parent Helper

This retained True Motion effect controls a child layer's inherited rotation and scale. It keeps the child on its parent's orbit. Apply it to the child and choose Normal, Locked or Weighted independently for scale and rotation.

Normal follows the parent. Locked preserves the child's own size or angle. Weighted scales the inherited rotation and uses the scale raised to the selected weight. Use the Keep upright, Keep size and Double rotation presets for common setups.

For linear scale weighting and rolling rotation, use the separate Parenting Helper effect added in AbsentMotion 5.0. Both IDs remain available so saved projects keep their original behavior.
